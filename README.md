# ss_enterprice

Odoo addons repository. One module:

* **[ss_enterprice](ss_enterprice/)** — SS Enterprise: a left sidebar with
  pinned menus and your logo, a chatter toggle for form views, and a
  brandable login page, for **Odoo 20.0**.

Add this directory to your `addons_path`, or clone it inside one:

```bash
git clone -b 20.0 https://github.com/shokhsmee/ss_enterprice.git
```

Branches follow the Odoo series they target (`20.0`).
See [ss_enterprice/README.md](ss_enterprice/README.md) for what the module
does and how to configure it.
